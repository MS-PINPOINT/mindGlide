Model and attribution

This browser edition derives from the public MS-PINPOINT MindGlide project and its pinned public checkpoint. The model is not retrained for the browser. It uses FP32 inference, the original 128 × 128 × 64 patches, 1 mm working spacing, 50% overlap and Gaussian blending.

Decoder transposed convolutions are rewritten as pointwise convolutions and spatial shuffles to support browser GPU execution. The rewrite is algebraically equivalent for this network’s non-overlapping upsampling blocks; floating-point kernels can still produce small numerical differences. Export and browser validation evidence is kept with the source code.

Code is released under the repository’s MIT licence. The converted weights are derived from the existing public checkpoint; this conversion does not assign a new licence to the original weights. See the upstream project and model repository for their terms.

Public example

The example is the ICBM 152 Nonlinear Asymmetrical template, version 2009c, 1 mm T1-weighted image, distributed by TemplateFlow. It is a public population template, not a visitor’s scan. Authors: V. Fonov, A. C. Evans, K. Botteron, C. R. Almli, R. C. McKinstry and D. L. Collins. See the template publication.
